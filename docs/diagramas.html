⚡ 2. Secuencia Técnica E2E: Ciclo de 8 Pasos GNAP

Secuencia completa entre el cliente Next.js 15, los Server Actions y el nodo de Rafiki Testnet, mostrando descubrimiento, cotización, consentimiento interactivo y pago saliente.

sequenceDiagram autonumber actor Usuario as Financiador / Comprador B2B participant Frontend as BiotaFlow UI (Next.js 15) participant Backend as Server Action (biotaflow.ts) participant ClientSDK as BiotaFlowClient (SDK ILP) participant Rafiki as Nodo Interledger (Rafiki Testnet) Usuario->>Frontend: Clic en 'Autorizar Pago' Frontend->>Backend: iniciarDonacion(montoCop, destino, tipo, intervaloIso) Backend->>ClientSDK: Resolver Billetera Receptora ClientSDK->>Rafiki: walletAddress.get(URL_RECEPTOR) Rafiki-->>ClientSDK: Detalles Billetera (authServer, resourceServer) Backend->>ClientSDK: Solicitar Grant Incoming Payment ClientSDK->>Rafiki: grant.request({ incoming-payment }) Rafiki-->>ClientSDK: Token no interactivo Backend->>ClientSDK: Crear Factura Entrante (Incoming Payment) ClientSDK->>Rafiki: incomingPayment.create({ incomingAmount: montoCOP }) Rafiki-->>ClientSDK: incomingPayment.id Backend->>ClientSDK: Solicitar Grant de Quote ClientSDK->>Rafiki: grant.request({ quote }) Rafiki-->>ClientSDK: Token de Quote Backend->>ClientSDK: Crear Cotización Multidivisa (EUR -> COP) ClientSDK->>Rafiki: quote.create({ receiver: incomingPayment.id }) Rafiki-->>ClientSDK: quote.id + debitAmount (EUR) + receiveAmount (COP) Backend->>ClientSDK: Solicitar Grant Interactivo GNAP (Outgoing Payment) ClientSDK->>Rafiki: grant.request({ interact, limits, interval }) Rafiki-->>ClientSDK: interact.redirect + continue.uri + continue.token Backend-->>Frontend: { success: true, interactionUrl } Usuario->>Rafiki: Portal Interactivo GNAP (Aprueba débito) Rafiki-->>Frontend: Redirección a /success?interact_ref=...&sid=... Frontend->>Backend: completarDonacion(interactRef, sessionId) Backend->>ClientSDK: Continuar Grant GNAP con interact_ref ClientSDK->>Rafiki: grant.continue({ interact_ref }, continue.token) Rafiki-->>ClientSDK: Access Token final para Outgoing Payment Backend->>ClientSDK: Ejecutar Pago Saliente ClientSDK->>Rafiki: outgoingPayment.create({ quoteId }) Rafiki-->>ClientSDK: outgoingPayment.id (Transacción confirmada) Backend-->>Frontend: Recibo digital emitido Frontend-->>Usuario: Muestra Recibo y Actualiza Balances ReFi
